# CMSRU Lecture Qbank

Practice questions taken straight from CMSRU lectures: questions printed on slides, in lecture notes, on formative quizzes, or asked out loud in lecture. Each explanation is the professor's own words (transcript or notes, quoted exactly) and the slide itself.

New weeks are released on Friday, after the week's last lecture is analyzed.

## Using it

Open the site, pick lectures, filter by where the question came from, and choose a mode:

- **Tutor**: answer, then see the professor's explanation right away.
- **Timed**: answer everything against the clock, then review.
- **Exam**: an Examplify-style screen with the Tool Kit (highlighter, calculator, notes, text size, alarms), flagging, strike-out, laboratory values, and the usual submit flow. You can switch Tutor mode on or off at any point during the exam.

## My Questions: quizzes from your own notes

Open **My Questions** in the sidebar to make a quiz from any lecture with the AI chatbot you already use:

1. Pick **Pull questions already in my material** or **Write new board-style questions**, then copy the prompt.
2. In ChatGPT, Claude, Gemini or similar, attach your slides or notes (a PDF works best), paste the prompt and send.
3. Paste the reply back. You can also attach the lecture PDF so explanations show the real slides and every quote is checked word for word against it.

Your quizzes then appear under a **My Questions** tab in Create Test, with the same Tutor, Timed and exam tools. They stay in your browser and are never uploaded. Use **Export** to save a quiz file you can send to a friend, who imports it on the same page. AI-written questions aren't checked by this site, so double-check anything that looks off.

Your answers are saved in your own browser only. Use **My progress → Export backup** before clearing browser data or switching computers.

## Contributing

Questions live in `data/lectures/` (format in `SCHEMA.md`). Contributors working with an AI assistant should point it at `CONTRIBUTING-LLM.md`. Every pull request is checked automatically: each quote must match the lecture transcript or notes word for word.

Not affiliated with ExamSoft or Examplify. The exam screen is an independent look-alike built for practice.
